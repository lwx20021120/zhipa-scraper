- app/bm25.py：简化 BM25（IDF+词频+文档长度归一化），中文用 **bigram 分词**（无词典：'提取商品名称和价格'→['取商','商品','品名','名称','价格'...]）
- 关键：中文整句会被当一个 token 导致匹配失败 → 必须 bigram
- direct_extract 集成：分块后 bm25_rank 选 top_k 相关块再喂 LLM（替代顺序取块）
- 测试：含导航/广告的块中商品块排前二；books 3页 BM25 直提 30 条正确

## 自适应停止 + 键盘 + hover（借鉴 browser-use/Crawl4AI 成品）
- 澄清：翻页抓取不需要多标签页（agent 点击下一页是同一标签页内导航，早已支持）
- **hover**：参考 browser-use actor/element.py 的 hover（移动到元素中心），实现 GET_ELEMENT_CENTER_JS 按编号取坐标 + page.mouse.move
- **press 键盘**：参考 browser-use KeyboardAction，agent 决策 action=press + text 按键名 → page.keyboard.press
- **自适应停止**：deep_crawler 连续 N 页（max_pages//10，最少1）无新增数据 → 提前停；去重前移（每页统计新增）
- **踩坑（第二次变量遮蔽！）**：press 分支 `key = decision.get("text")` 覆盖了 API Key 变量 → "Enter" 当 key 传 DeepSeek → 401（错误消息 ****nter 泄露）。修复：API key 改名 llm_key，局部变量用 press_key
- **踩坑**：AI 只 type 不按 Enter（搜索不生效）→ 提示词强调"输入后必须 press Enter" + 启发式（连续 2 次 type 同一元素自动补 Enter）
- 测试：agent 搜索 type→press→extract 20 行；深爬自适应停（books 去重 20 本）
- 服务已重启，HTTP 200

## 整合 browser-use 源码（用户要求"直接照抄整合"）
