## 修复：DataTable "DataRow/DataCells 列数不匹配" 报错
- **报错**：`each visible DataRow must contain exactly as many visible DataCells as there are visible DataColumns (4)`
- **根因**：flet DataTable 校验严格，`columns` 和 `rows` 是两步赋值，中间状态若 rows 的 DataCell 数 != columns 数就抛错（应用崩溃显示报错页）

- **修复**（app/ui/main_view.py）：三步赋值 ①先 `rows=[]`（rows=0 永不触发校验）②再设 `columns` ③再设新 `rows`
